2. 原M4-05—M6-06只作为M4-04需求来源，原M7-01—M7-03、M8-01和M8-03只作为M8-02需求来源。

4. 代码合并且功能真实可运行后改为`Implemented`；对应P0、适用人工复查和Evidence完成后才改为`Verified`。
5. 已完成任务卡和历史证据保持冻结；C8兼容扩展由M8-02承接。
6. REQ-022继续保持Verified；M8-02只做终验，不重新打开M3-06历史验收。
7. C8与自用交付证据统一进入`docs/test-evidence/M8-02/`并绑定实际受检Head。
8. 功能延期、Blocked或范围变化必须同步范围、功能清单、路线图、M8-02任务卡和P0矩阵。
