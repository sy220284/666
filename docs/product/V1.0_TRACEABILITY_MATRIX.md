## 维护要求

1. M0—M8-04保持历史Verified状态，不因M8-05维护任务重开。
2. M8-05只修复已确认竞态、错误语义和文档漂移，不改变自用发布边界。
3. 原M4-05—M6-06只作为M4-04需求来源；原M7-01—M7-03、M8-01和M8-03只作为M8-02需求来源。
4. 已完成任务卡、历史Migration和历史Evidence保持冻结。
5. 功能延期、受阻或范围变化必须同步范围、功能目录、追踪矩阵、当前任务卡和验证记录。
6. 代码签名、Apple公证、安装器及安装生命周期不属于V1.0；未来对外分发必须重新立项。
7. 当前独立任务数量为66；有效Verified、活动任务和下一任务资格必须由`TASK_INDEX`、Schema 2 Runtime、来源PR与GitHub Commit Status动态计算，禁止复制静态“全部Verified”结论。
