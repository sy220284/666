# WorldForge 隐私与日志规范

> 状态：Frozen  
> 更新日期：2026-07-28

## 1. 隐私原则

1. 项目内容默认只保存在用户本机。
2. 只有用户主动触发AI任务时，相关约束包才从本机发往用户配置的Provider。
3. WorldForge不提供请求中转、账号后台、云同步和作品托管。
4. 日志、诊断、统计和测试证据遵循最小化原则。
5. AI正文只进入Candidate，状态提取只进入pending StateProposal；日志不得成为任何创作内容旁路存储。

## 2. 数据分类

| 等级          | 数据                                                             | 默认处理                                                        |
| ------------- | ---------------------------------------------------------------- | --------------------------------------------------------------- |
| S0 公开       | 应用版本、开源许可证                                             | 可进入日志和文档                                                |
| S1 运行元数据 | Run ID、模型名、耗时、Token计数、错误码                          | 可记录，默认本地                                                |
| S2 项目元数据 | 项目ID、章节ID、字数、状态                                       | 仅本地记录，诊断导出前列明                                      |
| S3 创作内容   | 正文、设定、Prompt、约束全文、批注、日记、研究资料、模型原始响应 | 默认不进入普通日志                                              |
| S4 凭据       | API密钥、令牌、认证头、凭据密文                                  | 明文只进入受控请求内存；密文只进入safeStorage保护的本地凭据文件 |

## 3. 凭据存储与处理

V1凭据架构：

```text
明文密钥
→ Electron safeStorage调用可用的OS安全加密后端
→ 密文写入权限受限的本地凭据文件
→ app.sqlite只保存credentialRef
→ 请求期间短暂解密
→ 请求完成后清理内存引用
```

要求：

- `safeStorage`不可用或后端为`basic_text`等不安全实现时，阻断凭据写入与读取。
- 凭据文件、目录和临时文件使用当前平台可达的最小权限；Unix类平台文件目标权限为`0600`。
- Renderer、Preload响应、数据库、普通配置、错误details、剪贴板和诊断包不得包含凭据明文或密文。
- 不得把凭据值写入环境变量持久化、命令行参数、URL查询串或Crash报告。
- Provider请求完成、取消、超时或失败后必须释放可控凭据引用。

## 4. 允许记录的字段

默认结构化日志可以包含：

- 时间、级别、组件和事件名。
- requestId、taskId、runId、projectId的内部标识或不可逆表示。
- Provider ID、模型名称、协议和端点分类。
- 延迟、重试次数、Token统计和字符计数。
- 数据库操作类型、行数和耗时。
- 错误码、可重试标记和安全诊断ID。
- 内容Hash、Prompt ID/Version和Constraint Hash，但不保存原文。
- Candidate类型、完整度和结果引用ID，不保存正文。

## 5. 禁止默认记录

- 正文段落和完整章节。
- 完整System Prompt、PromptBundle、约束包和裁剪后的文本。
- 模型原始响应、流式delta和partial正文。
- 人物、设定、伏笔、StateProposal证据正文和项目日记全文。
- API密钥、凭据密文、认证头、Cookie和系统凭据值。
- 未脱敏本地绝对路径、用户名和设备名称。
- DOCX、附件或备份原始内容。
- 继续写作状态中的选区文本、正文片段或设定内容。

调试版本也不得用长期日志绕过这些限制。

## 6. 摘录边界

普通日志不保存内容摘录。专门的用户授权诊断允许保存最小局部样本时，必须：

1. 在界面列明将包含的内容。
2. 默认关闭。
3. 允许用户预览和删除条目。
4. 设定字符上限并移除相邻无关正文。
5. 不包含凭据、完整Prompt、约束全文或模型原始响应。
6. 标记授权时间、范围和诊断ID。

“只记录500字”仍属于创作内容，不能当作普通元数据。

## 7. 日志文件

建议：

```text
<project>.worldforge/logs/
├─ app-YYYY-MM-DD.jsonl
├─ core-YYYY-MM-DD.jsonl
└─ diagnostics/
```

项目日志可以只保存项目内ID；应用级日志不得复制正文。默认滚动保留14天或受空间上限约束，用户可手动清理。

日志删除、轮转和诊断导出失败不得影响正文事务、Candidate保存或备份。

## 8. 错误处理

- Renderer只获得标准错误码、安全文案、可重试标记、用户动作和诊断ID。
- SQL、堆栈、内部路径、Provider原始错误正文和模型响应只进入本地受控诊断，且仍需执行敏感字段过滤。
- 认证错误不得回显请求头、密钥、密文或包含凭据的URL。
- 数据库错误不得附带正文值。
- 取消不显示为危险错误；结果未知的写操作必须提示刷新权威状态。
- Schema解析失败不得把原始模型输出放入Renderer错误details。

## 9. 诊断包

诊断包默认包含：

- 应用版本、操作系统和显示器信息。
- 配置Schema，不含凭据值、密文和认证字段。
- 最近日志中的S0—S2字段。
- Migration版本和数据库检查结果。
- 测试或故障事件ID。
- Prompt ID/Version、ModelSupportProfile状态和Hash，不含完整Prompt与约束。

默认不包含：项目数据库、正文、Prompt全文、约束全文、备份、附件、Candidate正文、StateProposal证据正文和模型响应。

导出前必须显示清单，用户明确确认后生成本地文件。WorldForge不自动上传。

### 9.1 V1 C8当前实现

当前桌面端采用严格白名单导出，预览与最终文件共用同一个类型化对象，不从项目目录或日志目录扫描内容：

- 包含：应用版本与平台、Core健康状态、显示缩放摘要、日志条目计数元数据。
- 固定排除：项目正文、项目数据库、Prompt、Provider凭据和绝对路径。
- 导出前必须先预览清单并在当前界面显式确认；取消不产生文件。
- 导出文件使用随机化文件名、`0600`创建权限、临时文件同步后原子重命名，并返回字节数和SHA-256。
- 当前实现不收集日志正文、配置文件、数据库检查原文或设备名称；后续若扩展白名单，必须同步合同、安全测试与本节。

该实现只写入用户选择的本地目录，不上传、不自动附加到Provider请求，也不把导出路径回传Renderer。

## 10. AI请求可见性

AI任务界面应允许作者查看本次将发送的信息类别：

- 当前选区、章节或Final Version正文。
- 相关人物与设定。
- 前文尾状态。
- 文风样本。
- 规则与伏笔。
- 目标端点属于本机、局域网或外部服务。

V1不要求展示完整内部Prompt编辑器，但必须让作者知道哪些项目内容会离开本机。

`state_extract`界面必须说明：输出只形成待确认变化，AI不会直接更新权威状态。

## 11. 继续写作与本地统计

继续写作状态只允许保存：

- projectId、chapterId；
- 最近编辑时间；
- 光标位置、滚动位置和必要视图状态；
- 路径失效或只读状态所需的最小标识。

不得保存正文、选区文本、剪贴板内容、设定全文或Prompt。

人工写作统计只保存完成统计所需的来源、字符净变化、时间区间和聚合结果，不复制正文内容。

## 12. 测试

- 扫描默认日志，确认不含测试正文、Prompt样本、约束文本、模型响应和密钥。
- 故障、取消、断流、Provider错误、Schema错误和数据库异常同样执行扫描。
- 凭据文件权限、`safeStorage`不可用和`basic_text`后端阻断测试。
- 诊断包生成前后对文件内容做自动化白名单检查。
- Renderer状态快照不保存credential值、正文、完整Prompt或模型delta。
- 继续写作持久化状态不含正文或选区文本。
- GenerationRun、Candidate和StateProposal日志只包含允许的元数据与引用。
