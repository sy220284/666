# M11-06 作者日常写作界面精修

> 状态：Implemented
> 里程碑：M11 产品体验与智能创作协同  
> 优先级：P0  
> 执行分支：`work`  
> 目标分支：`main`

## 目标

基于真实作者连续写作模拟与高强度操作治理后的稳定内核，对日常正文界面做一次减法型精修：让正文成为视觉中心，把低频管理能力改为按需出现，同时把作者可见的智能创作相关术语统一为中文。

本任务不新增作品数据模型，不重做已经稳定的自动保存、历史版本、建议稿、规划、人物与世界或生成运行时；只调整作者看到什么、什么时候看到，以及对应的完整流程验收。

## 阶段定位

M11-05 已完成灵感胶囊与通用生成作用域，并通过后续高强度操作治理收口重复生成、快速切章和乱点状态问题。当前真实写作模拟显示，主要短板已经从数据安全转为默认界面信息密度过高，因此先完成日常写作界面减法，再进入后续长篇智能底座。

原计划中的长篇摘要、文风档案、智能任务分配、命令面板与 300万—500万字适配顺延至 M11-07，不与本次界面精修混在同一验收闭包。

## 非目标

- 不新增数据库表或 Migration。
- 不改变当前稿、历史版本、建议稿、规划、人物与世界的权威数据归属。
- 不重写自动保存、切章保护、建议稿采用/撤销或历史版本恢复逻辑。
- 不在本任务实现长篇摘要、文风档案、模型任务分配或语义检索。
- 不在本任务重做整个规划中心信息架构。
- 不删除现有高级能力，只降低它们在日常正文界面的默认视觉权重。

## 界面闭环

### 写作顶部

默认只保留：

- 返回；
- 作品名与当前章节；
- 保存状态；
- 目录显示/隐藏；
- 写作辅助显示/隐藏；
- 智能助手；
- 沉浸写作；
- 更多。

历史版本等低频入口进入“更多”，离开正文子页面时提供明确“返回正文”。

### 正文工具

- 段落类型、锁定、撤销、重做进入“段落工具”。
- 查找替换默认收起，可通过按钮或 `Ctrl/Cmd+F` 打开，`Esc` 关闭。
- 立即保存和复制正文进入“更多操作”。
- 字数、字符、段落、目标进度和保存状态移到底部状态栏。
- 自动保存继续是默认主逻辑，不用醒目的常驻手动保存按钮制造不信任感。

### 目录

写作侧栏只负责导航和新建章节；编辑、拆分、合并、移动、删除等结构管理能力保留在完整结构管理入口。

### 写作辅助

默认展开：

- 本章目标；
- 当前场景。

按需展开：

- 人物状态；
- 伏笔与修改任务；
- 上一章结尾；
- 部分信息不可用说明。

智能助手保留直接入口。

### 沉浸写作

继续保持当前成熟语义：目录、写作辅助和非必要工具隐藏，但正文、字数、保存状态、未保存输入和选区不得丢失。

### 全中文界面

- 作者可见智能功能使用“智能连接、智能模型、智能生成任务、智能建议稿、智能审阅、智能助手”等中文名称。
- 不新增 `AI连接 / AI模型 / AI任务 / AI建议稿 / AI审阅` 等中英混排旧称。
- OpenAI、Anthropic、Ollama、LM Studio、具体模型名等官方名称按官方写法保留。
- 内部代码标识不做破坏性改名。

## 安全、隐私与恢复

## 实施内容

1. 收敛写作顶部与默认说明文字。
2. 正文段落工具、查找替换和低频操作按需展开。
3. 统计与保存状态下移到底部状态栏。
4. 写作目录隐藏危险低频结构操作，只保留导航/新章。
5. 写作辅助按当前章相关性分层展示。
6. 写作与智能创作作者术语统一为中文。
7. 升级作者语言门禁，防止旧中英混排回归。
8. 同步现有完整流程测试到新入口层级，并新增日常写作界面完整验收。

## 人工验收

以网文作者日常连续写作为场景：

1. 新建作品后直接进入正文。
2. 连续输入并观察自动保存，不需要主动寻找保存按钮。
3. 快速切章，最后一次点击生效且正文不串章。
4. 写作中按需打开目录、辅助、查找替换、段落工具和智能助手。
5. 查看场景后返回正文，原滚动位置与焦点保持。
6. 进入/退出沉浸写作，正文和选区保持。
7. 在 1280×800 下确认默认正文空间明显大于精修前且关键入口仍可达。
8. 检查新增与修改界面文案均为中文。
