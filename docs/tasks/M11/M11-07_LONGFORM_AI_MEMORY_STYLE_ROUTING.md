# M11-07 长篇智能底座收口

> 状态：Planned  
> 里程碑：M11 产品体验与智能创作协同  
> 优先级：P0  
> 执行分支：`work`  
> 目标分支：`main`

## 目标

在 M11-06 完成作者日常写作界面减法后，基于 M11-04 的统一基础机制与 M11-05 的通用生成作用域/工作流处理器，完成三级长篇摘要、长篇上下文、文风档案、智能任务分配、生成主入口收敛与 `Ctrl+K` 命令面板，并承接原 V1.5 的长篇记忆、卷级连续性和 300万—500万字适配目标。

## 阶段定位

本任务由原未启动 M11-06 长篇智能底座计划顺延而来。编号调整发生在旧任务尚无 Runtime、Evidence、来源 PR 和实现提交时，不改写任何历史已验证任务。

M11-06 只负责日常写作界面减法与全中文体验；本任务承接后续需要新增领域能力、上下文能力和高级智能入口的工作，避免两类变化在同一 PR 混合验收。

## 非目标

- 不建立第二套故事事实、搜索索引、生成运行时或模型连接系统。
- 不恢复独立 L0—L5 记忆表或冷热物理迁移体系。
- 不以向量检索作为默认实现；只有真实评测触发才允许后续立项。
- 不回退 M11-06 已完成的日常写作界面减法。

## 依赖

- M11-06 有效 VERIFIED。
- 复用 M11-04 的生成指令版本权威、项目操作语义、界面请求所有权与原子导航。
- 复用 M11-05 的通用生成作用域与工作流处理器，不建立第二套生成路由/运行时。

## 真实承接基线

任务启动时以 M11-06 已验证主线为唯一基线补入 Runtime；当前仅保留计划状态。

## 关联

- 长篇摘要：章节摘要 → 卷摘要 → 全书摘要。
- 长篇上下文：继续由现有约束包统一裁剪、追踪来源和校验新鲜度。
- 文风档案：项目级可复用风格配置与偏离检查。
- 智能任务分配：按任务、作者偏好、模型支持与回退策略选择已有受信连接。
- 智能创作入口：日常作者入口收敛为“规划这一章 / 生成这一章 / 改写选中内容”，高级来源和融合能力进入二级区域。
- `Ctrl+K`：复用现有全文搜索与原子导航，统一搜索、跳转和命令执行。
- 300万—500万字长篇规模验收。

## 职责、状态所有权与依赖方向

1. 长篇摘要是可重建派生数据，不是人物、世界、连续性等权威事实。
2. 现有约束包继续是唯一智能上下文权威。
3. 文风档案不得复制现有网文章奏配置拥有的字段。
4. 智能任务分配只选择已有受信连接和凭据；凭据仍只在本地服务侧使用。
5. 生成主入口只做作者层级收敛，不改变内部成熟的骨架/正文/改写/融合任务类型。
6. `Ctrl+K` 复用现有全文搜索和导航，不新增平行搜索服务。

## 数据库与 Migration

计划新增单一派生表 `story_digests`，包含范围、来源摘要、语义修订、新鲜度、内容和生成来源；文风档案与任务分配优先使用类型化项目设置，不新增平行表。

Migration 必须追加，不改写已发布历史 Migration。

## 程序通信、事件与错误

- 摘要读取/重建使用具名接口或现有生成工作流。
- 文风和任务分配使用类型化设置服务。
- 失效摘要、无可用模型、摘要失败、文风样本不足使用稳定可解释错误。
- 项目/章节/范围切换后的旧界面请求不得写回当前页面。

## 界面闭环

### 智能生成主入口

作者主入口：

- 规划这一章；
- 生成这一章；
- 改写选中内容。

融合、来源、目标字数、继续生成、候选数量等高级能力进入二级区域但不删除。

### 命令面板

`Ctrl+K` 统一搜索与执行：章节、人物、设定、伏笔、历史版本、写作模式和现有页面动作。作者可见命令保持中文。

### 文风与长期记忆

作者只看到可理解的文风、长篇记忆和来源说明，不暴露内部摘要层级、哈希、语义修订等技术字段；技术详情按需展开。

## 安全、隐私与恢复

- 继续满足本地数据与用户自配模型连接边界。
- 摘要可重建，克隆/恢复按重新生成策略处理。
- 不复制凭据，不跨凭据边界猜测模型连接。
- 关键权威事实必须回查正式人物、世界、连续性数据，不能只信摘要。

## 性能预算

增加 300万字与500万字真实长篇样本，至少覆盖启动、项目打开、切章、连续写作、自动保存、历史版本、全文搜索、命令面板、故事知识窗口查询、上下文组装、摘要增量失效/重建、备份恢复、项目切换请求隔离、内存和 SQLite 增长。

不允许因作品规模增加而在每次生成或导航时扫描全文。

## 实施内容

1. 三级故事摘要及增量失效。
2. 约束包接入人物关系、故事摘要、文风档案和有效例外。
3. 文风档案和文风偏离检查。
4. 智能任务分配与显式回退策略。
5. 智能生成作者主入口收敛和高级设置分层。
6. `Ctrl+K` 搜索、导航与命令执行。
7. 300万—500万字长篇性能/恢复验收。
8. 语义检索真实证据门；未触发则不新增向量层。

## 自动化测试

任务启动后必须执行当前永久质量矩阵，并专项覆盖：

- 定稿成功但摘要失败；
- 摘要失效/重建/克隆重新生成；
- 跨卷人物状态、关系、时间线、知情、伏笔和人物成长连续性；
- 长篇上下文裁剪与来源追踪；
- 文风档案与网文章奏职责不重叠；
- 智能连接指定、回退和拒绝；
- 生成高级能力仍可达；
- 命令面板复用全文搜索和原子导航；
- 300万/500万字真实长篇性能与恢复；
- 语义检索触发评测及明确结论。

## 人工验收

从长篇作者真实使用角度验证：连续写作、跨卷续写、查看长程人物/伏笔信息、智能生成本章、切换模型、使用命令面板跳转，以及关闭重启后继续工作均保持正确上下文。

## Evidence

任务启动后保存到：`docs/test-evidence/M11-07/`。

除常规记录外必须保存 300万/500万字性能与内存结果、跨卷连续性结果以及语义检索证据门结论。

## 回滚策略

整体回滚摘要、文风、任务分配和命令面板应用层增强；摘要可清空重建，Migration 保持追加。不得恢复第二套上下文、搜索、模型连接或独立 L0—L5 记忆体系。

## 完成条件

- 三级故事摘要可重建并具备来源、新鲜度和增量失效。
- 约束包仍是唯一智能上下文权威。
- 跨卷生成具备可验证的连续性召回路径。
- 文风档案与网文章奏职责不重叠。
- 智能任务分配服从连接、凭据、模型支持和生成指令版本边界。
- 日常生成入口分层清晰，高级能力仍可达。
- `Ctrl+K` 复用现有全文搜索和原子导航。
- 300万字、500万字性能、恢复、重启、失败路径、覆盖率与完整流程测试全部通过。
- 是否需要语义检索由真实评测证据决定。
