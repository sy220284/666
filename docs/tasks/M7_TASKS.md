# WorldForge M7 完整UI与体验整合任务摘要

> 状态：Frozen  
> 用途：里程碑导航与阶段门说明；不可替代独立任务卡。

## 阶段目标

复用M5-00基础体验骨架，完成首次使用向导、三条创作路径、M6全功能工作台接入、全局状态仲裁、主题、无障碍和目标显示环境终验。

## 阶段退出门

- 完整向导和三条路径不分叉数据、命令或项目模型。
- M7-02接入全部M6功能，但不重建M5-00基础导航、三栏布局、沉浸视图或模式状态。
- 所有功能有统一入口、完整交互状态和真实Core/TaskProtocol状态。
- StatusArbiter没有形成Renderer权威状态、跨项目残留或请求风暴。
- Appearance和Theme保持单一状态源，主题切换不改变业务结果或用户工作位置。
- 目标视口、主题、键盘、焦点和无障碍验收通过。

## 执行规则

- 只能通过`ACTIVE_TASK.md`激活其中一张任务卡。
- M5-00基础骨架保持权威，M7只做向导、功能整合和终验。
- 没有一致性或性能证据时，M7-02不得新增统一状态聚合接口。
- 未满足依赖不得提前实现后续任务。
- 每张任务完成后同步追踪矩阵与证据目录。
