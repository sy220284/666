# M10-08 已知风险

1. Renderer TSX 当前单元覆盖率基线较低，但已全量进入报告，并以最大未覆盖数量执行只升不降门禁。后续新增未测语句、分支、函数或行会失败；基线只能在真实测试改善后收紧。
2. 纯 DOM/JSX 组合与浏览器生命周期主要由 Electron E2E 验证。可独立执行的状态转换、数据映射、错误分支和业务决策仍应提取为稳定逻辑并补单元测试，禁止用无意义渲染机械凑数。
3. React Hooks 专项插件尚未写入锁文件。本任务没有手工伪造依赖状态；后续需在可复现依赖治理中引入与 React 19、ESLint 10 兼容的插件。现有类型感知 Promise、await 与 switch 规则已生效。
4. 已发布 Migration 的历史无条件回填按冻结截止版本读取。新 Migration 仍必须使用 WHERE 或显式审查注解，历史文件不得反向改写。
5. `pnpm/action-setup` 当前仍声明 Node 20，GitHub Actions 在 Node 24 兼容模式下给出弃用警告。工作流实际运行成功，后续应在上游 Action 发布兼容版本后更新固定 SHA。
6. 文件规模只用于人工观察，不参与合并资格。结构风险继续由循环依赖、跨层方向、Feature 边界和状态所有权门禁控制。
7. Toolchain Export 启动前遗留的临时分片提交仍存在于 `work` 历史，但最终 PR 树已删除相关文件；受控 Squash 合并不会把二进制产物带入 `main`。
