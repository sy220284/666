# 已知风险与回退

## 风险

1. SQLite 与文件系统不存在共同事务。Recovery 通过确定请求身份、正式文件改名前校验、数据库事务内登记核对、持久操作日志和可识别副作用清理形成补偿闭环；后续修改任一步顺序时必须保留故障注入测试。
2. 恢复操作日志保存在备份根目录的项目级 `.operations` 中。日志损坏或意图不一致会保守返回冲突，禁止静默创建第二个恢复副本。
3. Provider 绑定传输使用适配器创建时已批准的地址集合。Host、SNI、证书验证与 Origin 不得因重构改回普通 `fetch` 二次解析。
4. 分支历史曾短暂包含仅用于自签名 TLS 测试的合成私钥，当前树已删除。Secret Scan 白名单只批准精确提交、路径和行号，不得扩大到通配路径或真实凭据。
5. PR 级 Quality 使用 `cancel-in-progress`。手动重跑可复用工作流 Job 会与同一并发组冲突并被外部取消；验收只认新 Head 触发的完整永久检查。
6. Package Smoke 仅在打包输入变化时执行。本任务未修改打包脚本、锁文件或发布工作流，不得把可选跳过解释为产品测试缺失。

## 回退

按同一任务整体回退 Provider 绑定传输、Recovery 幂等与补偿、Renderer 请求代次与保存顺序、路径预算、测试及 M10-11 治理文件。

回退不得恢复普通 `fetch` 二次 DNS 解析、随机备份身份、无持久日志的恢复副本、正文失败后推进续写位置，或按字符而非 UTF-8 字节截断路径。
