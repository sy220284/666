# M12-03 已知风险

1. Theme B 像素级基线固定在 Linux 2560×1440；跨平台与多显示规格由独立平台体验/DPI矩阵覆盖。后续合法视觉变化仍必须先取得至少两份独立 Actions 稳定见证，再更新基线，禁止直接“截图覆盖”。
2. 性能门禁在早期某个仅格式变化的 Head 上出现过一次备份/恢复 P95 与事件循环延迟抖动；同一实现随后重跑成功，最终冻结提交 `eecf8113...` 的 Performance `32152967733` 也直接成功。该现象只能按 Runner 抖动监控，不得据此放宽性能预算。
3. 打字机模式的原生中文输入专项使用 Windows 内置 Microsoft Pinyin；macOS/Linux 由各自平台体验门禁验证应用行为，但不声称使用同一输入法引擎。
4. 三栏审阅只有在真实基础版本可用时成立；基础版本缺失时降为既有双栏 Diff 是设计行为，后续不得为了“始终三栏”伪造基础文本。
5. StoryComment 批处理必须继续保持“全集合先校验、同一写事务提交”的语义；任何新增批处理动作都应复用同一事务边界。
6. 快捷键扩展不得绕过 `COMMAND_CATALOG`、`rebindable`、输入法 composition、模态焦点与只读边界，也不得引入任意脚本、Shell、宏或动态模块执行能力。
7. 合并前静态闭包状态只表示实现和验收材料已经收口；最终有效 `VERIFIED` 仍需 Controlled Merge 后的 `main-verification` 与 `task-verification/M12-03` 成功。
