# 规划模式与研究资料状态所有权

## 唯一规划模式

- `AppDisclosureMode` 与既有 Settings／`PlanningModeWorkbench` 保持唯一规划模式权威。
- 完整规划工作台不再维护局部“简明／完整”状态，也不再提供重复模式切换按钮。
- 现有规划 E2E 按真实模式入口重新打开工作台，不依赖已删除的重复内部按钮。

## 五类研究筛选

- `tests/unit/research-discard-restores-editor.test.ts` 使用真实渲染组件分别执行搜索、标签、来源、归档和故事对象筛选。
- 每个筛选场景均先修改当前笔记，随后断言不会出现放弃修改确认，并验证草稿仍能完成保存。
- 当前对象被列表过滤后编辑器继续挂载，并向作者显示“不在当前筛选结果中”。
- 切换真实笔记、新建、删除、归档和离开工作台继续复用统一的未保存保护。
