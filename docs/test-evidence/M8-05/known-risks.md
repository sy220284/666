# M8-05 已知限制

- M8-05不扩大V1.0自用便携交付边界；Windows代码签名、macOS签名与公证、系统安装器、自动更新和安装生命周期仍不属于当前范围。
- Provider响应限制保护应用免于无界读取，但合法且接近16 MiB上限的响应在低内存设备上仍可能产生性能压力；应优先缩小生成范围。
- 真实Provider账号、线下模型质量、本地GPU模型矩阵不属于本次维护验证；离线基础写作和确定性服务桩路径继续受永久门禁保护。
- 请求代次只控制Renderer是否接收过期响应，不取消已经进入Core的普通只读查询；权威数据安全仍由项目边界、事务、锁定和恢复点保证。
- 词典保存与搜索可以并行完成，因此最后完成的操作可能更新页面状态说明；搜索结果、替换计划和词典数据仍由各自通道独立维护。
- Ubuntu虚拟显示Electron验证不等同于物理混合DPI、多屏插拔、真实中文输入法和实体读屏人工体验。
