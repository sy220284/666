- stable Release必须验证Windows Authenticode签名，以及macOS Developer ID签名、公证与stapling；缺少实际验证证据时阻断发布。
- draft允许明确标记的仓库所有者自用未签名工件；系统安装器、自动更新和安装生命周期不属于本矩阵。
- 模型质量未达标时对应AI任务降级；无AI基础写作闭环保持可用。
