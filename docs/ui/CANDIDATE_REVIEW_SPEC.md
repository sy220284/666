# WorldForge 建议稿审阅与冲突交互规格

> 状态：Frozen with M8-05 Maintenance Addendum  
> 目标：让作者在长章节中高效比较、选择、融合和回退AI建议稿，同时保持当前稿安全边界。  
> 更新日期：2026-07-30

## 1. 核心原则

1. 建议稿默认不进入当前稿。
2. 作者可以整稿采用、逐段采用、按场景节拍采用、融合、丢弃或保留。
3. 建议稿比较不以单一评分替代作者判断。
4. 冲突必须在提交前解决，保存序号变化不能静默覆盖。
5. 应用建议稿是一个原子当前稿事务，可整体撤销。
6. 未完成建议稿始终显示“不完整”，不能直接定稿。
7. 历史版本与建议稿复用差异呈现组件，但保持只读、恢复和采用语义分离。
8. 长章节性能优化不能隐藏修改、锁定、冲突或来源信息。

## 2. 入口

- AI任务完成后的“查看建议稿”。
- 写作工作台AI区域的建议稿历史。
- 章节历史中的未处理建议稿。
- 快速改写升级为结构性改写。
- 融合任务完成后。
- 历史版本中的“与当前稿比较”。

进入采用流程前先提交当前未保存编辑。保存失败时阻止采用，但允许只读查看建议稿或历史版本。

## 3. 分组与列表

建议稿按以下分组展示：

```text
待审阅
已采用
已丢弃
情节骨架
未完成内容
```

每项显示：

- 生成任务类型和时间；
- 完整度；
- 字数；
- 基础保存序号；
- 场景节拍来源；
- 模型与支持等级；
- 锁定跳过和风险摘要。

历史版本单独按时间、类型和标签排列，不混入建议稿状态分组。

## 4. 页面结构

```text
顶部栏
├─ 章节标题 / 来源类型 / 状态
├─ 分组与对象切换
├─ 视图切换
├─ 差异导航
└─ 退出 / 重新生成

主体
├─ 当前稿
├─ 建议稿或历史版本
└─ 差异、上下文与选择控件

底部操作栏
├─ 已选择段落
├─ 冲突与锁定摘要
├─ 应用到当前稿
├─ 恢复历史版本为新当前稿
└─ 丢弃/保留建议稿
```

历史版本页面不显示“采用此段”；其操作是比较、导出或恢复为新当前稿。

## 5. 视图模式

### 5.1 并排比较

宽屏默认：左侧当前稿，右侧建议稿或历史版本。适合完整章节通读和块级选择。

### 5.2 行内差异

在单一阅读流中标出删除、增加和修改，适合窄屏、局部改写和快速复核。

### 5.3 单稿专注

一次显示当前稿或对比稿，页边显示差异数量和切换按钮。

### 5.4 只看修改

折叠未变化内容，只显示差异块及有限上下文。可以展开任一折叠区，但不得跳过锁定或冲突摘要。

### 5.5 情节骨架并排

多个T0骨架可以卡片并排；完整正文首版最多并排两稿，更多建议稿通过切换查看。

视口不足时，并排自动切换为行内或单稿，不产生整页横向滚动。

## 6. 差异呈现

匹配优先级：

1. 稳定`logicalBlockId`。
2. 块新增、删除、移动、拆分、合并。
3. 块内中文字符差异。

视觉：

- 新增：来源标识、细边和轻底纹。
- 删除：中性删除标记，避免大面积红底。
- 修改：字符级强调。
- 移动：显示来源和目标位置。
- 锁定：保留锁定线、图标和禁用原因。
- 冲突：文字、图标和结构共同表达，不能只靠颜色。

## 7. 长章节上下文折叠

长章节差异采用有界渲染：

```text
差异块
├─ 修改前有限上下文
├─ 修改内容
└─ 修改后有限上下文

连续未修改内容
└─ 折叠占位，可按需展开
```

规则：

- 首屏优先渲染可见差异和附近上下文。
- 未修改块默认折叠，不一次性挂载整章DOM。
- 展开状态属于临时界面状态，不修改当前稿或建议稿。
- 差异导航按上一处/下一处定位。
- 1.2万行性能用例中首屏可见行保持有界。
- 字符差异按分片或Worker计算，取消后停止未来结果回写。

## 8. 同步滚动

- 并排模式默认按对应块同步。
- 对应关系断裂时以最近稳定锚点同步。
- 用户可以解除同步独立阅读。
- 场景节拍跳转时两侧定位对应内容。
- 大段新增或删除不强制像素级同步。

## 9. 选择单位

支持：

- 整个正文建议稿；
- 场景节拍；
- 完整正文块；
- 冲突项。

V1不支持逐字符拼接采用。作者可以进入受控手动合并处理细粒度内容。

## 10. 段落操作

每个建议稿块提供：

```text
采用此段
保留当前段
加入手动合并
查看生成依据
```

批量操作：

- 本场景节拍全部采用。
- 本场景节拍全部保留当前。
- 采用全部非冲突段。
- 清空选择。

锁定块的采用控件禁用并说明原因。

## 11. 情节骨架比较

卡片显示：

- 倾向名称；
- 场景节拍顺序；
- 核心冲突升级；
- 信息释放；
- 结尾钩子；
- 必选节拍覆盖；
- 风险摘要。

操作：选为T1基础、编辑后继续、按节拍融合、丢弃。不得显示“AI评分最高”作为默认选择。

## 12. 融合

### 场景节拍融合

为每个场景节拍选择来源建议稿。

### 结构与表达融合

```text
结构来源：建议稿A
表达来源：建议稿B
保留当前稿：指定正文块
```

融合生成新的merge建议稿，仍需审阅，不直接写入当前稿。系统只对拼接缝隙生成必要过渡，并显示来源和原因。

## 13. 冲突类型

| 类型 | 原因 | 处理 |
|---|---|---|
| 保存序号冲突 | 生成后当前稿整体变化 | 重新计算对应关系 |
| 内容Hash冲突 | 对应块已被作者修改 | 保留当前、采用建议、手动合并 |
| 缺失块 | 当前稿或建议稿块不存在 | 确认新增或删除 |
| 锁定冲突 | 目标块已锁定 | 保留当前或退出后解锁 |
| 结构冲突 | 拆分、合并、移动无法自动判断 | 进入结构冲突视图 |
| 项目或章节失效 | 对象已关闭、删除或切换作品 | 停止采用，保留建议稿 |

## 14. 冲突处理与手动合并

P0默认双区：当前稿、建议稿，下方显示选择结果和手动编辑区。高级三栏属于P1。

手动合并：

- 以当前稿副本为起点；
- 可插入建议稿句段；
- 结果在提交前仍是临时内容；
- 保存时再次校验保存序号和锁定；
- 来源记录为mixed并关联建议稿ID。

## 15. 应用前摘要

显示：

- 将修改多少正文块；
- 新增、删除、移动数量；
- 锁定跳过；
- 当前保存序号是否匹配；
- 是否创建采用前恢复点。

无冲突时在页面底部确认区完成，不额外增加模态层。

## 16. 应用后反馈

- 返回写作工作台并定位第一个修改块。
- 显示“已应用X个段落 · 撤销”。
- 来源可追踪到建议稿。
- 保存状态以Core事务结果为准。
- 建议稿更新为已采用，未采用部分保留在记录中。

所有主题共用同一命令、冲突和撤销机制；Theme B只增加表现层，不分叉业务逻辑。

## 17. 回退

### 即时回退

Ctrl/Cmd+Z或“撤销本次应用”执行inverse patch。

### 重启后回退

在历史操作或历史版本页选择采用前恢复点，恢复为新当前稿。

### 限制

应用后继续大量编辑时，整体撤销可能形成新冲突，应进入回退预览，不静默覆盖后续修改。

## 18. 未完成建议稿

允许：阅读、复制、局部采用完整可判断的块、继续生成、创建新建议稿。  
禁止：一键定稿、隐藏不完整标记、冒充完整任务结果。

## 19. 性能与取消

| 范围 | 目标 |
|---|---:|
| 5000字差异首屏 | ≤500ms |
| 5000字完整差异 | ≤1.2s |
| 20000字及以上 | 渐进计算并可取消 |
| 1.2万行自动化用例 | 首屏可见行有界，不挂载完整未修改内容 |

取消、对象切换或章节切换后，旧计算结果不得覆盖新差异视图。

## 20. 快捷键

| 操作 | 快捷键 |
|---|---|
| 并排/行内切换 | Alt+1 / Alt+2 |
| 单稿切换 | Alt+3 |
| 只看修改 | Alt+D |
| 上一处/下一处差异 | Shift+F7 / F7 |

快捷键必须可通过按钮完成；自定义快捷键属于P1。
