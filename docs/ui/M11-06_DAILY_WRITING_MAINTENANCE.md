# M11-06 日常写作界面维护附录

> 状态：In Progress  
> 适用：M11-06 作者日常写作界面精修  
> 更新日期：2026-08-13  
> 性质：对冻结 V1.0 UI 规格的局部维护附录，不改写历史已验证任务。

## 1. 权威范围

本附录仅覆盖日常写作工作台的信息密度、入口层级、作者术语与对应验收。对以下旧规格中的写作界面描述，以本附录为准：

- `INFORMATION_ARCHITECTURE.md` 的写作工作台、右侧上下文栏及作者可见智能入口描述；
- `SCREEN_SPECIFICATIONS.md` 的写作工作台、本章写作辅助、沉浸写作及作者可见智能连接术语；
- `EDITOR_INTERACTION_SPEC.md` 中正文工具的默认披露层级。

正文补丁、自动保存、锁定、建议稿、历史版本、恢复、规划数据及 Core 权威边界继续沿用原规格，不因本次界面减法改变。

## 2. 日常写作工作台

```text
顶部：返回 / 作品·章节 / 保存状态 / 目录 / 写作辅助 / 智能助手 / 沉浸写作 / 更多
左：紧凑卷章目录（导航 + 新建章节）
中：正文编辑器
右：本章写作辅助
底：字数 / 字符 / 段落 / 目标进度 / 保存状态
```

原则：正文始终是视觉中心；低频工具默认收起，不以按钮数量制造“功能完整感”。

### 顶部

- 顶部保存状态用于快速扫视，不建立第二个读屏 live region。
- “更多”承接历史版本等低频入口。
- “智能助手”进入现有智能创作与建议稿能力，不新增第二套生成运行时。

### 正文工具

- 段落类型、分隔线、撤销/重做、块锁定放入按需展开的“段落工具”。
- 当前章查找/替换默认关闭，通过按钮或 `Ctrl/Cmd+F` 在正文编辑状态按需打开。
- “立即保存”“复制正文”进入正文“更多操作”。
- 自动保存保持原语义，界面减法不得改变保存事务、Revision 或切章保护。

### 底部状态

- 字数、字符、段落与目标进度下沉到底栏。
- 底部保存状态是唯一 `role=status` / `aria-live` 保存播报源，避免同一事务重复播报。
- 简明模式只显示作者所需保存文案；完整/专业模式可继续显示“保存序号”作为审计信息。

## 3. 目录与完整结构管理

日常写作目录只承担：

- 卷章浏览；
- 切换章节；
- 新建章节。

以下操作不在紧凑目录暴露：编辑卷章、拆章、并章、块移动、卷移动、删除、回收站。

这些高风险或低频操作进入“规划 → 打开完整规划”的卷章目录执行；简明规划与完整规划继续共享同一份权威数据，测试必须显式进入完整规划后再验证结构操作。

## 4. 本章写作辅助

默认展开：

1. 本章目标；
2. 当前场景。

按需展开：

- 人物状态；
- 伏笔与修改任务；
- 上一章结尾；
- 其他来源/告警信息。

辅助面板继续只读现有规划、连续性、叙事规划、待办和版本权威数据，不建立第二套摘要或故事事实。

## 5. 沉浸写作

沉浸模式保留：

- 作品/章节识别；
- 正文；
- 字数；
- 保存状态；
- 退出沉浸入口。

隐藏目录、写作辅助、段落工具、查找替换和非必要顶部动作。保存失败与数据风险仍必须可见。

## 6. 作者术语

作者界面统一使用“智能连接 / 智能助手 / 智能审阅 / 智能建议稿”等中文任务语言。内部协议、代码标识、历史技术文档中的 `AI`、Provider、GenerationRun 等技术名称不因本附录改名。

本次不新增能力，只调整作者可见术语与入口层级，因此不改变底层 IPC、领域模型或 GenerationRun 权威。

## 7. 验收增量

M11-06 至少验证：

- 默认正文工具为收起态，功能可按需展开；
- `Ctrl/Cmd+F` 与按钮入口均能打开当前章查找；
- 紧凑目录没有编辑、拆并、移动、删除入口，新建章节仍可用；
- 完整规划仍可执行原结构高风险操作；
- 本章目标与当前场景默认可见，其他辅助信息按需展开；
- 沉浸模式仍显示字数与保存状态；
- 顶部保存状态不重复声明 live region，底部状态可被读屏读取；
- 简明模式不暴露保存序号，专业模式保留审计级保存序号；
- Windows Microsoft Pinyin、macOS/Windows/Linux 作者主路径保持通过；
- Linux 1280×800 四主题视觉基线必须在所有临时菜单收起后的默认写作态采集；
- 更新视觉基线时继续满足两次独立全绿运行的 Artifact provenance，不以单次新 Hash 直接替代历史基线。

## 8. 非目标

- 不新增 Migration；
- 不新增 Main / Preload / Contracts / Core 命令；
- 不把 M11-07 的长篇摘要、文风档案、智能路由、`Ctrl+K` 或 300万—500万字适配提前塞入本任务。
