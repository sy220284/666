# WorldForge V1.0 页面规格

> 状态：Frozen with M8-05 Maintenance Addendum  
> 用途：前端实现和桌面E2E验收依据。  
> 更新日期：2026-07-30

## 1. 启动页

目标：覆盖首次启动、最近作品、Core失败、路径丢失、Schema过新和项目损坏。

```text
顶部：应用名称 / 设置 / 帮助
主体：继续写作 / 新建作品 / 导入已有正文
下方：最近作品
底部：版本 / 本地数据位置 / Core状态
```

主要操作：打开、创建、导入、重新定位路径、移除最近记录、进入设置。

## 2. 新建作品向导

1. 快速开始、完整流程、导入已有或空白作品。
2. 名称、频道和作品位置。
3. 可跳过的作品任务书。
4. 可跳过的关键人物。
5. 第一章目标、场景节拍或直接写作。

完成后原子创建工作空间、项目库、首卷章和活动当前稿。向导取消或失败不留下不可识别半成品。

## 3. 首页

新手：继续写作、一步建议、最近作品和新建/导入。  
专业：最近作品、最近章节、运行任务、健康风险和空白作品。

规则：主动提示最多2条；数据风险优先；不展示运营图表。

## 4. 规划工作台

```text
左：卷章与大纲树
中：作品任务书 / 大纲节点 / 章节 / 场景节拍编辑
右：人物、设定、伏笔、弧光和目标摘要
```

主要操作：新建卷章、剧情弧和场景节拍；排序；关联实体和伏笔；跳转正文。

风险：移动有关联正文的场景节拍先预览；删除规划节点不自动删除正文；规划变化不自动调用AI。场景节拍移动与正文块移动分别确认并复用恢复点及正文补丁安全链。

## 5. 写作工作台

```text
顶部：作品/章节、模式、搜索、任务、保存状态
左：卷章目录
中：标题、正文编辑器、状态栏
右：本章 / AI / 人物 / 设定 / 检查
```

正文区：受控宽度、来源与锁定页边标记、选区工具条、场景分隔。  
底部状态：保存、字符数/纯文字字数/目标进度、AI阶段和风险摘要。

主要操作：输入、粘贴、当前章查找、撤销、锁定、快速改写、T0/T1、结构性改写、建议稿、历史版本、定稿和沉浸写作。

## 6. 本章写作辅助

正式位置：写作工作台右侧“本章”区域。

页面内容：

```text
章节标题与刷新
├─ 本章目标：目标、核心冲突、预期结果
├─ 场景节拍：标题、必选状态、目标字数比例、目标
├─ 相关人物状态：已确认动态状态与知情状态
├─ 伏笔与待办：状态、注意级别、跳转动作
├─ 上一章结尾：优先定稿版本，缺失时当前稿
└─ 部分信息不可用：可展开警告
```

规则：

- 数据来自真实规划、连续性、叙事规划、写作待办和历史版本查询。
- 只读作品仍可查看；所有写操作保持禁用。
- 刷新使用独立请求代次；后发刷新使先发结果失效。
- 切换作品或章节后旧结果不得回写。
- 读取失败只影响辅助面板，正文编辑和保存不受影响。
- 场景节拍、伏笔和待办可精准跳转并返回来源滚动和焦点。

## 7. 沉浸写作

保留：返回、作品/章节、正文、保存、字数和可关闭轻量AI入口。  
隐藏：一级导航、侧栏、校验详情和非紧急提示。

保存失败和数据风险必须继续显示。退出后恢复原滚动与侧栏状态。

## 8. 建议稿审阅

顶部：章节、任务类型、建议稿分组、建议稿切换、并排/行内/只看修改。  
中部：当前稿、建议稿、结构/字符差异、场景节拍导航和采用动作。  
底部：选择数量、冲突数量、应用、保留和丢弃。

分组：

```text
待审阅
已采用
已丢弃
情节骨架
未完成内容
```

视口不足时并排自动转为行内或单稿。长章节折叠未修改上下文，只保留有限可见行和差异附近内容。采用继续经过锁定、保存序号、内容Hash、项目归属和恢复点检查。

## 9. 冲突处理

P0默认：当前稿与建议稿双栏，附结果摘要。  
每项显示冲突类型、基线变化、当前内容、建议内容、保留当前、采用建议、手动合并或跳过。

所有冲突解决后重新校验保存序号并一次事务提交。高级三栏合并结果视图属于P1。

## 10. 历史版本

显示时间、类型、标签、字数、来源保存序号、与当前稿比较、恢复为新当前稿和导出。

- 不提供编辑历史版本按钮。
- 定稿版本默认不可删除。
- 与当前稿比较复用建议稿差异组件，但保持来源和操作语义分离。

## 11. 设定工作台

### 11.1 实体

人物、地点、势力、道具、能力、规则、事件和自定义实体。

### 11.2 中区标签

基础资料、已确认设定、当前状态、历史状态、人物弧光、关系和引用章节。

### 11.3 结构化关系字段

普通作者使用名称选择器，不手填内部对象标识：

- 人物、地点和章节；
- 定稿版本；
- 时间线事件；
- 伏笔及依赖关系。

选择器显示名称与必要上下文，保存时提交受控ID。目标已归档或失效时要求重新选择，不猜测替代对象。

### 11.4 人物弧光

- 弧光类型、目标、状态和说明。
- 里程碑顺序、关联章节、依赖和`planned/hit/skipped`。
- pending设定更新建议单独显示，不能冒充已命中。
- 接受、编辑接受和拒绝通过统一入口。

## 12. 时间线、知情与伏笔

时间线：列表/简化轴、起止、精度、人物、地点、依赖和冲突。  
知情：知道、相信、怀疑、误解、未知、来源和获得章节。  
伏笔：生命周期、回收窗口、超期、关联章节和依赖。

V1.0不以复杂自动布局关系图作为主入口。

## 13. 检查工作台

左侧：本章、全书、连续性、设定、人物弧光、文风、机械校对、网文节奏、写作待办。  
中部：严重度、标题、章节、锚点、依据和状态。  
右侧：原文、依据、建议、跳转、忽略、静音、降级、误报和转待办。

检查结果使用统一导航目标；目标失效时停止跳转并提示重新运行检查。

## 14. 全文搜索与安全替换

### 14.1 页面结构

```text
标题与索引重建
状态：说明、待更新数、失败数
搜索：关键词、当前稿/历史版本/人物设定范围
结果：来源、标题、摘录、打开命中位置
批量替换：查询、替换文本、预览、锁定摘要、恢复点并替换
作品词典：词条、类型、替换目标、备注、保存与删除
```

### 14.2 请求与等待状态

| 通道 | 等待状态 | 互斥范围 |
|---|---|---|
| 全文搜索 | `searchPending` | 搜索、替换和索引按钮；不禁用词典 |
| 安全替换 | `replacePending` | 搜索、替换和索引按钮；不禁用词典 |
| 作品词典 | `dictionaryPending` | 词典保存和删除；不禁用搜索/替换 |
| 全文索引 | `indexPending` | 搜索、替换和索引按钮；不禁用词典 |

规则：

- 同一通道的最新请求是唯一可更新结果和清理等待状态的请求。
- 不同通道互不递增对方请求代次。
- 词典保存或删除发生在搜索/替换期间时，两侧各自正常完成。
- 作品切换和页面卸载统一失效全部通道并清理可见等待状态。
- 索引重建在搜索/替换/索引任务期间禁用，避免同一搜索工具区重复操作。
- 批量替换始终先预览、检查锁定、创建恢复点并重校验计划。

## 15. 网文节奏页

- 体裁节奏配置开关与参考区间。
- 爽点密度趋势和对应场景节拍证据。
- 章末钩子建议与结尾锚点。
- 更新目标与实际字数。
- 黄金三章只显示前3章。

所有提示明确标注“建议”，关闭后不再运行或展示。

## 16. 写作待办与批注

- 写作待办按章节、场景节拍、正文块和状态筛选。
- 作品检查问题可转待办。
- 完成待办后可重跑来源检查。
- 批注提供轻量查看、编辑和删除。
- 复杂批处理属于P1。

## 17. 导入、导出与恢复

导入：文件检查→编码/格式确认→分章预览→合并/拆分/重命名→摘要→提交。  
导出：选择全书/卷/章、指定历史版本、TXT/Markdown/DOCX、标题顺序和目标文件。  
恢复：选择已验证备份→新目录→验证→注册副本→打开。

预览期间项目库不变化；取消和失败清理临时数据；恢复默认不覆盖当前作品。

## 18. 设置

- 通用：语言、启动行为、最近作品和默认模式。
- 编辑器：字体、字号、宽度、行高、段距和首行缩进。
- 外观与显示：Theme A/B、界面缩放、工作区位置、减少动态和高对比。
- AI连接：Provider、地址、模型、凭据引用、连接测试和支持等级。
- 备份：频率、保留数、空间上限和目标目录。
- 检查、节奏与词典：默认检查、静音规则、节奏配置和作品词典。
- 高级：日志、诊断、数据库检查、全文搜索重建和开发信息。

打字机模式、自定义快捷键和高级三栏冲突视图属于P1，不显示可用占位。

## 19. AI错误页面状态

`AI_RESPONSE_TOO_LARGE_014`显示：

- 标题：AI返回内容超过安全上限。
- 说明：系统已经停止接收，正文和本地数据没有修改。
- 动作：缩小生成范围、降低输出长度或检查模型服务。
- 不展示原始响应正文，不归类为普通结构解析失败。

## 20. 页面通用状态

每页必须覆盖：空、首次加载、刷新、部分失败、完全失败、只读、边界拒绝、运行、取消、冲突和恢复成功。

未实现的P1/V1.5功能不得以可点击占位出现。
