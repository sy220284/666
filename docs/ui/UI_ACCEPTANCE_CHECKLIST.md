# WorldForge UI专项验收清单

> 状态：Verified Maintenance  
> 用途：V1.0 UI、交互、显示、无障碍及后续维护验收。  
> 证据：桌面E2E、单元测试、性能测试、键盘记录或明确人工验收。  
> 更新日期：2026-08-15

## 1. 文档与实现一致

- [ ] 一级导航与信息架构一致。
- [ ] 页面结构与页面规格一致。
- [ ] Design Token统一，业务组件无散落颜色和尺寸。
- [ ] 未实现功能不显示可用入口。
- [ ] 新手/专业模式共用数据、命令和页面组件。
- [ ] Theme A/Theme B不分叉业务逻辑。
- [ ] 功能变化同步信息架构、页面规格、交互规格、验收、功能目录和追踪矩阵。

## 2. 基础写作

- [ ] AI未配置时可新建作品、建卷章、写作、保存、历史版本、导入导出和恢复。
- [ ] 最近作品可打开、重新定位或移除。
- [ ] Core启动失败有诊断和重试。
- [ ] 中文输入不丢字、不重复；composition期间不提交半成品。
- [ ] 粘贴清除脚本、字体、颜色和布局污染。
- [ ] 自动保存不阻塞输入，保存状态只以Core事务为准。
- [ ] 保存失败持续可见，可重试和复制未保存文本。
- [ ] 字数在编辑器、目录、统计和导出预览一致。
- [ ] 历史版本只读，恢复产生新当前稿。
- [ ] 损坏作品可只读浏览和恢复副本。

## 3. 写作工作台

- [ ] 左卷章、中正文、右上下文结构清楚，正文为视觉中心。
- [ ] 保存、字数、任务和检查摘要可见但不抢眼。
- [ ] 章节切换保留编辑和滚动位置。
- [ ] 侧栏可折叠，沉浸写作只改变视图。
- [ ] 跳转其他工作台后可返回来源位置和焦点。
- [ ] 本章写作辅助显示真实目标、场景节拍、人物状态、伏笔、待办和上一章结尾。
- [ ] 写作辅助读取失败不影响正文编辑和保存。

## 4. 锁定、正文补丁与历史版本

- [x] 段落可锁定和解锁。
- [x] 锁定块无法输入、删除、移动、拆分和合并。
- [ ] AI、替换、拆并章不能修改锁定块。
- [ ] 保存序号或内容Hash冲突进入专门视图。
- [ ] 建议稿采用一次事务完成，应用后可整体撤销。
- [ ] 重启后可恢复采用前状态。
- [ ] 历史版本和历史正文不可直接修改。

## 5. 规划、设定与连续性

- [ ] 大纲树支持键盘和拖拽；规划变化不自动改正文。
- [ ] 删除场景节拍不删除正文。
- [ ] 跨章移动有关联正文时显示影响预览。
- [ ] 已确认设定、当前状态、历史状态和AI建议视觉分离。
- [ ] 时间线、知情、伏笔和人物弧光有列表入口。
- [ ] pending设定更新建议不显示为权威状态。
- [ ] 常用关系通过名称选择器编辑，不要求作者手填对象标识。
- [ ] 目标已失效时要求重新选择，不猜测替代对象。

## 6. AI任务与建议稿

- [ ] AI阶段对应真实程序事件，无总量时不显示虚假百分比和倒计时。
- [ ] 切章或切页后任务继续且不串稿。
- [ ] 取消后500ms内反馈，未来增量不进入界面。
- [ ] 中断或取消结果明确标记未完成。
- [ ] AI不可用不影响基础写作、搜索、备份和导出。
- [ ] T0可绕过；T1临时流不直接写当前稿。
- [ ] 快速改写应用前原文不变，跨段操作进入完整建议稿流程。
- [ ] 融合结果显示场景节拍来源。

## 7. 建议稿与历史版本审阅

- [ ] 建议稿按待审阅、已采用、已丢弃、情节骨架和未完成内容分组。
- [ ] 支持并排、行内、单稿和只看修改。
- [ ] 视口不足时自动切换布局。
- [ ] 结构差异和中文字符差异可读。
- [ ] 新增、删除、移动、拆分和合并区分清楚。
- [ ] 支持整稿、正文块和场景节拍级采用。
- [ ] 锁定块不可采用。
- [ ] 冲突可保留当前、采用建议、手动合并或跳过。
- [ ] 不使用单一AI分数强制推荐。
- [ ] 5000字差异首屏≤500ms、完整≤1.2s。
- [ ] 1.2万行自动化用例首屏可见行有界。
- [ ] 20000字以上渐进计算可取消。

## 8. 作品检查、全文搜索与节奏

- [ ] 确定性、统计和AI语义问题可区分。
- [ ] AI问题使用风险文案和证据，可忽略、静音、降级、误报和转待办。
- [ ] 全文搜索显示当前稿、历史版本和人物设定来源。
- [ ] 搜索结果一次点击定位；目标失效时不误跳。
- [ ] 批量替换先预览、检查锁定、创建恢复点并重校验计划。
- [ ] 节奏指标为建议级、可关闭，黄金三章只作用于前3章。

## 9. 搜索工具异步隔离

- [x] 全文搜索、安全替换、作品词典和全文索引使用四个独立请求通道。
- [x] 同一通道后发请求使先发响应失效。
- [x] 不同通道互不失效；词典保存或删除不能使搜索/替换永久等待。
- [x] 每个通道只清理自己的等待状态。
- [x] 作品切换或页面卸载统一失效全部旧响应。
- [x] 词典写入期间只禁用词典保存和删除，不错误禁用搜索结果读取。
- [x] 搜索、替换或索引处理中禁用重复搜索工具操作。
- [x] Renderer请求代次不替代Core项目边界、锁定、事务或幂等校验。

## 10. 导入导出与恢复

- [ ] TXT编码低置信度可人工选择。
- [ ] 导入先预览分章、合并、拆分和重命名，预览期间项目库不变化。
- [ ] DOCX异常和恶意文件有安全错误，取消或失败后清理临时数据。
- [ ] 导出明确选择历史版本。
- [ ] 日常、重大操作和手动快照分组清楚。
- [ ] 最后一份已验证备份不能删除。
- [ ] 恢复默认到新目录，原作品不覆盖。

## 11. 状态、错误与帮助

- [ ] 核心页面有空、加载、部分失败、完全失败、只读、冲突和恢复状态。
- [ ] 用户取消不显示红色错误。
- [ ] 保存失败、只读和损坏使用持续Banner。
- [ ] 首页主动提示最多2条，数据安全优先。
- [ ] 悬停、首次提示和页面帮助使用统一Registry。
- [x] `AI_RESPONSE_TOO_LARGE_014`显示“AI返回内容超过安全上限”。
- [x] 响应超限说明系统已停止接收且正文未修改。
- [x] 响应超限提供缩小生成范围、降低输出长度或检查服务动作。
- [x] 响应超限不显示原始响应正文，不误称为结构解析失败。

## 12. 视觉、响应式与无障碍

- [ ] Theme A浅色、深色、护眼和高对比完整。
- [ ] Theme B浅色、深色和印章表现层完整。
- [ ] 主题切换不改变业务结果；AI来源不用绿色表示更优。
- [ ] 减少动态时所有功能可用。
- [ ] QHD（2560×1440）作为正式最低支持，可完成新建、写作、AI、建议稿、定稿和导出，无整页横向滚动。
- [ ] QHD 100/125/150/200%、QHD+、UWQHD与4K文字和图标清晰，弹层不越界。
- [ ] 21:9正文限宽，主要操作靠近工作区。
- [ ] 混合DPI和显示器移除后窗口仍可见。
- [ ] 核心流程可全键盘完成，焦点顺序和焦点陷阱正确。
- [ ] 状态不只靠颜色表达，屏幕阅读器可读保存、任务、冲突和恢复状态。

## 13. 产品阻断

以下任一项失败，当前维护任务不得Verified：

- 基础写作必须依赖AI。
- 保存状态与Core事务不一致。
- 主题分叉业务逻辑。
- 锁定、保存序号、内容Hash、建议稿或历史版本硬保证被绕过。
- 搜索或词典操作可以使界面永久等待。
- 作品切换后旧响应进入新作品界面。
- Provider超限响应继续无界读取或误用输出解析错误码。
- QHD（2560×1440）在正式缩放矩阵下无法完成核心流程。
- 恢复覆盖原作品。
- 未实现入口伪装可用。

UI Acceptance不单独验证代码签名或Apple公证；但stable Release必须在产物门禁中验证Windows签名、macOS签名、公证与stapling。系统安装器以及安装/升级/卸载生命周期仍不属于V1.0阻断项。
